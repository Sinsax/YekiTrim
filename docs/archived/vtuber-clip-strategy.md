# VTuber 切片策略

> B 站生态导向的切片方法论，后续可泛化到 YekiTrim 工具设计中。

## 核心公式

**标题（信息差）→ 3s 内最高密度 → 节奏压缩不留空 → 情绪单位完整收束**

---

## 一、标题：制造信息差

观众在信息流里做决策的时间不到 1 秒。标题的核心任务是让 ta 产生"这和我以为的不一样"的感觉。

### 三种常见信息差形式

| 形式        | 说明            | 示例                     |
| --------- | ------------- | ---------------------- |
| **结果前置型** | 把出人意料的结果放在标题  | 「当 V 说自己要学中文，结果开口就是方言」 |
| **反转暗示型** | 暗示有转折发生       | 「以为在认真唱歌，直到她看了一眼弹幕」    |
| **身份冲突型** | 人设 vs 真实之间的差距 | 「高冷人设维持了 3 秒」          |

### 错误 vs 正确

- ❌ 「2024.3.15 直播剪辑」——只有信息，没有信息差
- ✅ 「她花 10 分钟画的图，AI 3 秒就画完了」——观众想看到底差多少

### 自检

标题写完后问自己：**"这有信息差吗？"** 如果没有，重写。

---

## 二、前 3 秒：最高密度前置

B 站信息流竖屏自动播放、默认无声音。前 3 秒决定了观众会不会点进去并且戴耳机。

### 同时做到两件事

1. **视觉抓住注意力**——画面本身有信息量（表情包、字幕大字、画面抖动），而不是平淡的直播画面
2. **听觉给预期**——爆点台词前置，然后黑屏/定格 0.3s 再开始正片

### 实操技巧

> 把整段切片里**最炸的一句台词**剪到最前面，然后接「这一切还要从 5 分钟前说起...」

这样就同时有了信息高密度 + 叙事结构。

---

## 三、节奏：去气口 + 情绪单位完整性

### 去气口

直播里有大量"空气"——思考时的"呃..."、喝完水放杯子的声音、翻页的空白、笑完之后没人说话的尴尬。这些在直播里是自然的呼吸，在切片里是**拖垮完播率的元凶**。

**目标：每句话之间的间隔 ≤ 0.3s。**

YekiTrim 的 `silence-remove` 可直接完成这一步。

### 情绪单位完整性

一个完整的情绪单位 = **铺垫 → 爆发 → 收束（反应）**。

- ❌ 主播说了一个梗 → 观众笑起来 → 剪掉（缺收束，观众在等结尾，完播率下降）
- ✅ 主播说了一个梗 → 观众笑起来 → 主播自己吐槽了一句 → 结束

最后那段"收束"是让观众心理上觉得"嗯，看完了"的关键。

---

## 四、操作流程

```
选材 → 剪粗稿(保留情绪单位) → 压节奏(去气口) → 前 3s 重组 → 起标题
```

| 步骤   | 操作                     | 工具/方法                              |
| ---- | ---------------------- | ---------------------------------- |
| 选材   | 弹幕密度高峰期就是潜在爆点          | YekiTrim events.json 的 popularity 排序 |
| 剪粗稿  | 保留完整情绪单位，宁长勿短          | 手动                                 |
| 压节奏  | 去掉所有 >0.3s 的静音段        | YekiTrim `silence-remove`            |
| 重组开头 | 把最高密度的一句放最前面 +「事情是这样的」 | 手动                                 |
| 标题   | 写完后问自己「这有信息差吗」         | 无                                  |

---

## 五、与 YekiTrim 工具的对应关系

| YekiTrim 功能        | 对应策略                   |
| ---------------- | ---------------------- |
| `silence-remove` | 节奏压缩：去气口               |
| 事件检测按弹幕热度排序      | 辅助选材：找到高人气片段           |
| 字幕裁剪 + 偏移        | 配合前 3s 重组，字幕对齐新时间轴     |
| 情绪单位完整性          | 目前需手动判断，可考虑后续自动检测"收束点" |
