第 2 / 4 步

这套在解决什么

  • 配置的失败大多不是"配错参数"，而是"某家不能用了" —— 首屏直接给体检结论与影响面。
  • 新用户走四步就能从零到能用，不用先理解"链路 / 覆盖 / 生效值"这些词。
  • 修复动作与诊断结论挨着（"两条链路切到 main"就在横幅上），不用自己找地方改。

代价 / 什么时候别用

  • 看板是只读的，日常改参数仍要进另一个视角 —— 两个视角就要维护两套入口。
  • 体检是"探一下"，要服务端支持草稿测试与逐接口状态，否则看板只能是假的。
  • 向导只服务首次；跑熟之后它会一直躺在 tab 里没人点。
