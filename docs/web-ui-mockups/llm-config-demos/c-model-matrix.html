检测这一列指着一条 401 的接口 —— 矩阵能看见引用，但看不见"这条请求会不会失败"。点 cheap 修密钥，或把这格改到 main。

这套在解决什么

  • 「哪支模型被几条任务用」一眼可见 —— 删模型/换密钥前就知道会打掉谁（引用可见性）。
  • 单次点击完成分配，不需要"选接口 → 再选模型"两段式。
  • 能力不符的格子直接标灰：不会配出一条跑不通的链路。

代价 / 什么时候别用

  • 矩阵随模型数增长：20 支模型 × 5 任务 = 100 格，扫视成本高于方案 A 的五张卡。
  • 参数（温度/上限/推理）塞不进格子，还得另开一处 —— 表格只解决"用谁"，解决不了"怎么发"。
  • 接口连接信息只能压成一条，改密钥要多跳一层。
