这一版的结构

  • 保留两个子页（模型配置 / 链路配置），沿用现在的 tab 形状。
  • 默认落在哪一页由配置状态决定：没模型 → 模型配置；配好了 → 链路配置。
  • 模型配置里，接口是分组头，加模型 / 改密钥全部就地展开，没有抽屉。
  • 链路配置里，任务表是唯一主体：一个下拉、参数只显示被覆盖的键。

为什么按状态落地

  • 没配好时，链路页是一屏空下拉——留着它当默认只会让人困惑。
  • 配好后，日常 90% 的动作（换模型）都在链路页，模型配置成了"几个月碰一次"的仓库。
  • 用户手动切过就记住；但未配置时忽略记忆，避免上次停在链路页 + 清空配置 = 打开就是空页。
