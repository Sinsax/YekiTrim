这套在解决什么

  • 绝大多数人只有一家接口、只想让它跑起来 —— 首屏就是那条唯一的路，没有岔口。
  • 「按任务分模型」仍然在，但默认不出现：它是优化项，不是必答题。
  • 三步点把"我现在走到哪了"讲清楚，替换掉一大片看不出进度的表单。

代价 / 什么时候别用

  • 多接口用户（检测走便宜、精修走贵的）会每天都得展开高级 —— 那时方案 A / C 才是正解。
  • 换接口 = 覆盖当前那三行，看不出"历史还有两份接口"（要靠"已有 3 份接口"进抽屉）。
  • 向导式的分步感在"回访"时会退化成普通表单，收益衰减得比其他三套快。
