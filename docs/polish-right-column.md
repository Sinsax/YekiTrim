# 精修页右栏的定稿形态（`PolishView.vue`）

> 这页是 `webui/src/views/AGENTS.md` 里「右栏按钮行有宽度预算」那节的**展开版**。
> 卡只留规矩，多轮改动的来龙去脉放这里 —— 卡有 24576 B 硬预算，超了整份会被 DSH 丢掉。

## 定稿结构（2026-10-06 第八轮）

```
右栏 = 一块卡片（判据 ⑰ 钉"块数只能是 1"）
├─ 页签 [项目设置] [画面尺寸]          ← 同一位置切换（用户：「位置和项目设置是一个位置」）
├─ 字幕 / 弹幕                        ← 行排版，每组占满 300px
│    字幕字体 · 弹幕字体 · 偏移滑杆 · 显示弹幕
├─ 区域设置                           ← **贴纸 + 区域合并**（第八轮口径）
│    [emoji][ysyk][…]                 ← 贴纸来源（`ss-options` 多选开关）
│    [弹幕位置][人物位置][自动]         ← 三颗同一行；「自动」点一下切 自动/固定
├─ ─────── `.lane-sep` 分隔符 ───────
├─ LLM 剪辑 / 渲染导出
└─ 任务（可折叠，默认折叠；展开是浮层）
```

左侧那列只剩 `#tl-props-host`（时间轴块属性面板的 Teleport 挂载点，必须是空容器）。

## 为什么是"行"而不是"列"

- 右栏宽 **300px**，卡片内边距 24、列间距 16 ⇒ 三列时每列只有 **83px**。
- 83px 下实测：两颗框选按钮横排放不下（56+44=100 > 83），字体下拉选项被截断。
- 第六轮我（AI）把用户说的「三个区域放在同一行」读成"三组**并排成三列**"，是**误读** ——
  用户原意是"同一片区域"，**整体仍是行排版**（第七轮纠偏）。
- ⚠️ **别再引回 `.lane-cols`**：判据 ⑰ 直接钉"没有列容器"，行排版下框选两颗按钮是**同一行**。

## 多轮口径对照（都是用户原话）

| 轮次 | 用户要求 | 落点 |
|---|---|---|
| ① | 「还是把轨道设置放在右侧常驻」 | 轨道设置从左栏搬到右栏 |
| ② | 「画面尺寸退回原来的那个页面」（= 切面板那种） | 与项目设置**同位置、页签切** |
| ③ | 「你把项目设置全删了我是没想到的」 | 输出（LLM/渲染/任务栏）**原样搬回** |
| ④ | 「项目设置页 → 删除，不需要这个」 | 删掉那颗 `router-link` |
| ⑤ | 「轨道设置内的东西和项目设置合并」 | 合并成**一块卡片**（此前拆成 2~3 块，把时间轴挤出首屏） |
| ⑥ | 「任务改成折叠的模式…展开时不要挤占下方控件，是浮在上层的」 | 任务栏折叠 + 详情绝对定位浮层 |
| ⑦ | 「整体还是以行来排版」 | 三列改回**行排版** |
| ⑧ | 「贴纸和区域合并，显示为区域设置」 | 两组并一组，两行结构 |

## 判据在哪

- 静态：`webui/scripts/check-layout-invariants.mjs` 的 ⑰ / ㉗（每条带变异自证）。
- 真页面几何：`.workbuddy/probe-v6.mjs`（量横向溢出、三颗同行、时间轴是否在首屏、展开是否挤占）。

## 踩过的坑

- ⚠️ **判据别用 `<div class="row">…</div>` 正则找一组按钮**：非贪婪解遇到**内层** `</div>`
  就截断，永远跨不过那组按钮。改用"三颗之间不许出现 `div.row`/`div.col`"。
- ⚠️ **别把 `position:absolute` 写到 `.job-wrap` 本身**：整条任务栏会逃出卡片跑到页面底部
  （实测 top 571→1930）。详情才该 absolute，`.job-wrap` 只做 `relative` 锚。
- ⚠️ **别用 `scrollWidth > clientWidth` 判横向溢出**：`input[type=range]` 天生就报
  （3px 宽滑块的 `scrollWidth` = 10）。要量"子元素视觉右缘是否越过容器右缘"。
- ⚠️ **改这种嵌套块别手数括号**：两轮手数都数错（SFC 报 `Element is missing end tag`）。
  写个逐行 `<div>`/`<template>` 深度追踪，直接定位到"`.grid` 自己少一个 `</div>`"。
