## 自带字体（已内嵌，首次启动自动装好）

两支自带字体都是 **SIL OFL-1.1**（可商用 / **可嵌入** / 可再分发）：

| 字体 | 用途 | 体积 |
|---|---|---|
| **Noto Sans SC** | 中文正文（字幕 / 封面） | 10.0 MB |
| **Noto Color Emoji** | 彩色 emoji（**CBDT** 位图，**非 COLRv1**） | 9.9 MB |

- **字节直接内嵌在 `yekitrim.exe` 里**：编译期 `include_bytes!`，源在
  [`../crates/yekitrim-core/assets/fonts/`](../crates/yekitrim-core/assets/fonts/)；
- **首次启动自动落盘**到字体库 —— **不需要联网**，也不需要手动下载；
- **OFL 全文一并内嵌**，与字体一起落盘到各自的 `LICENSE.txt`（源文件是
  `NotoSansSC-Regular.OFL` / `NotoColorEmoji-CBDT.OFL`，OFL 要求随附）；
- 所以**装完打开就能选字**。

字体自身的许可是 SIL OFL-1.1，与**项目许可**（Apache-2.0，见 [许可](licensing.md)）是两回事。

运行时的兜底栈：**库里那支 → `Microsoft YaHei` → `Noto Sans SC` → `sans-serif`**。

## 为什么中文正文换成了 Noto Sans SC（2026-10-02）

⚠️ 中文正文那支 **2026-10-02 由「霞鹜文楷 Lite」换成「Noto Sans SC」**（体积更小、观感更中性）。

- **老工程不受影响**：它们配置里显式写着的旧字体名，照旧按原名解析。
- **为什么不找 CC0 字体**：**CJK 领域基本没有 CC0 的正文字体** —— CC0 不含 OFL 那种"保留字体名
  与许可声明"的保护，中文项目普遍不采用。实际可用上限就是 OFL。

## 命令

万一库里那两支被删了，可以装回来（**幂等、仍然不联网**）：

```bash
yekitrim fonts list                          # 看库里有什么
yekitrim fonts install                       # 重新装上还缺的自带字体
yekitrim fonts install --id NotoColorEmoji   # 只装某一支
```

正常情况下**不需要跑它们** —— 首次启动已自动装好；这两条是**修复入口**。
`fonts list` 会逐条列出：id / 内部族名 / 显示名 / 体积 / 是否自带 / 是否默认 / 装没装。

## 想用别的字体

把字体文件丢进**程序目录**的 `resources/fonts/`，或者在「字体库」页导入。
它和 `yekitrim.exe`、`.yekitrim/`、`stickers/` 同级：

```
<程序目录>/
  yekitrim.exe
  .yekitrim/
  stickers/
  resources/fonts/          ← 放 .ttf / .otf；丢进去就会出现
    <字体名>/               ← 导入的字体按「一支一个目录」存
      font.ttf
      FONT.toml             ← 元数据（内部族名 / 显示名 / 许可 / 是否自带）
```

`FONT.toml` 记的就是四件事：**内部族名**（渲染时按它对字体）、**显示名**（下拉里给人看）、
**许可**、**是否自带**。

## 在哪里选字体

| 用途 | 位置 |
|---|---|
| **字幕字体** | 精修页「生成与导出」卡 → LLM 剪辑参数块 → 「字幕字体」下拉（**按片段保存**） |
| **封面字体** | 封面设计器 → 「排版」组 → 「字体」下拉 |

选完**保存即生效**，不用重跑任何任务：**预览**与**"渲染导出"出的成片**都会用这个字体。

**没选字体的工程**会优先用 `Noto Sans SC`（栈里写的是它的**内部族名**）——这个"默认位"只作
**初始化设定**：界面上的字体下拉**只列库内字体**，不会再给一个「（系统默认）」的选项
（自带字体就在库里，回到系统栈必然是更差的选择）。

## ⚠️ `.ttc` / `.otc`（字体集合）用不了

浏览器的 `@font-face` **不认字体集合**。收进来会出现"**预览回退系统字体、出片却用了它**"——最难查的
那种错位。导入时会被**直接拒绝**，请先拆包成单个 `.ttf` / `.otf`。

## ⚠️ 乐米波波体：免费商用，但**不含嵌入式用途**

**想要圆润可爱的标题风格？** 可以自行安装或下载 **乐米波波体**（LemiBoBoTi，杭州乐米网络科技）。
官方授权地址：<https://font.leminet.cn/>。

注意它的授权是"**免费商用**"但**不包括嵌入式用途**：

- 商用需按其要求取得**免费商用授权书**；
- 把字体文件**内嵌进软件或 APP** 则**必须另行授权**。

**本项目因此不随包分发该字体** —— 请你自行获取、自己放进 `resources/fonts/`，并遵守其条款。

## 实现备注（改代码前看）

- 字体库分两层：**用户库** `<数据目录>/users/<uid>/resources/fonts/`（单人 = 当前管理员那份，
  `Local` 与登录管理员落到同一处），**公用库** `<数据目录>/global/resources/fonts/`
  （自带字体是公用素材，装一份所有人共用）；`YEKITRIM_DATA_DIR` 可覆盖数据目录，
  见 [目录结构](file-layout.md)。缺 `FONT.toml` 的目录也算一条
  （元数据取默认值），老布局（`.ttf` 直接平铺在库根目录下）**仍被认**。
- 库内**落盘路径保证纯 ASCII**，给人看的名字住在 `FONT.toml`（`id` / `display_name`）：
  路径里出现非 ASCII 会让底座出片那条 `drawtext=fontfile=…` 腿访问违例（`0xC0000005`）。
- 浏览器/底座两条腿都从同一个「内部族名」出发，别在各自那侧再拼一遍字体名 —— 拼法一分叉就会出现
  "预览一个样、成片一个样"。
