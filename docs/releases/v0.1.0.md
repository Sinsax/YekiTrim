## 前置条件

| 依赖 | 说明 |
|---|---|
| `ffmpeg` + `ffprobe` | **必需**，需在 `PATH` 中（音频提取、剪切、截图、静音检测、渲染） |
| Chrome / Edge | 精修**渲染**与**封面**需要（服务端用 headless Chrome 出图）；`/api/health` 会给出探测结果 |
| ASR 模型 | 首次转写时自动下载到 `<exe同级>/.vtrim/models/`（约 1.5 GB，`vtrim download` 可预取） |
| 磁盘 | 源录播 GB 级；切片 ≈ 保留时长 × 2–4 Mbps；精修渲染产物最大（1080p60 约 3.6–5.4 GB/小时输出） |
| GPU 编码（可选） | NVENC / QSV / AMF 自动探测，缺失时回退 `libx264` |

## 快速开始

```powershell
# 图形界面（本机使用）
vtrim.exe server --open          # 默认 127.0.0.1:7788，浏览器自动打开

# 命令行全流程
vtrim.exe init D:\records\stream.mp4 --danmaku D:\records\stream.ass
vtrim.exe process                # 提取音频 → 转写 → 事件检测 → 剪切
vtrim.exe status                 # 查看进度

# 精修（对某个切片）
vtrim.exe polish init output\clips\clip-01
vtrim.exe polish process output\clips\clip-01
vtrim.exe polish render  output\clips\clip-01
```

WebUI 页面：总览 / 预览（转写·事件检测）/ 切片 / 精修（时间轴·字幕·封面）/ 设置 / 模型 / 任务。
`vtrim.exe server` 会在 exe 同级自动生成 `.vtrim/config.toml`、`.vtrim/llm.toml`（首次运行），模型与贴纸库也在该目录下。

## 本版包含的能力

- **核心管线**：`init / extract / process / transcribe / detect / cut / correct / silence / status / download`
- **精修引擎**：`polish init|llm|process|render|cover|preview|doctor|test`、本地贴纸 `stickers list|test|scan|build`
- **WebUI**：项目多开、事件时间线、切片管理（一键全切 / 单事件剪切 / 去静音）、精修编辑器（时间轴 / 字幕 / 贴纸 / 封面设计 / 预览 / 渲染）
- **服务端加固（本次发布含）**：未注册 `/api/*` 返回 JSON 404；同一时刻只允许一个长任务（409 + 明确提示）；**真正的取消**（阶段/批次边界生效）；SSE 先回放历史、`Lagged` 不再误报失败；`Range` 请求 416/206 修复（旧版 `bytes=500-100` 会整数下溢）；项目内文件读写路径校验、`polish.toml`/`events.json`/`vtrim.toml` 读改写串行化；渲染/预览服务按目录复用（不再每次点击泄漏端口）
- **已知测试目标**：`vtrim-polish/tests/text_*.rs` 与 `vtrim-render-core` 的 test 模块在**工作区级 `cargo check --all-targets`** 下仍有既有编译错误（与运行无关；按包检查 `cargo check -p vtrim-cli --all-targets` 为 0 warning）

## 已知限制（请按此边界使用）

1. **无鉴权，仅本机使用**：默认只监听 `127.0.0.1`。对外监听必须显式加 `--allow-remote`——本服务可读写本机任意工程目录并调用 ffmpeg / Chrome，不要暴露到不可信网络。
2. **单用户、单长任务**：同一时刻只跑一个长任务（后来者收到 409 + 提示），任务进度按 SSE 推送。
3. **wgpu 真渲染入口已隐藏**（该功能暂缓，未纳入本稳定版）；`/api/health` 的 `wgpu_render` 为 `false`。
4. **不提供上传**：视频/弹幕以服务器本地文件为准（WebUI 里的"打开项目"选择服务器上的路径）。
5. 多用户（账号隔离）与录播姬自动入库属于**远期目标**，见 `docs/superpowers/specs/2026-09-12-multi-user-server-design.md`。

## 升级与备份

- 升级：替换 `vtrim.exe` 与 `webui/` 即可；`.vtrim/`（配置、模型、贴纸）保留。
- 备份：拷贝 `<exe同级>/.vtrim/`（全局配置 `config.toml`/`llm.toml`、`server.toml`、模型、贴纸）与各工程的 `vtrim.toml`、`output/`。
- 模型体积较大，迁移机器时建议直接复制 `.vtrim/models/`，避免重新下载。
