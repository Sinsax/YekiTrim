## ⚠️ 两处会影响老用户的变更（升级前请看）

### 1. 配置文件会**被自动升级一次**（含备份）

所有配置文件顶层新增 `config_version`。老文件（没有这个键 = v0）在**第一次读取时自动迁移**：
清掉 4 个从来没有读取方的历史键（`asr.align_model` / `asr.max_segment_duration` /
`asr.segment_merge_gap` / `cutting.silence_noise_db`）并补上版本号。

| 文件 | 会不会被改写 |
|---|---|
| `.yekitrim/config.toml` · `llm.toml` · `server.toml` | ✅ **会**，且**先备份**成 `<名>.bak-v0`（原样保留，不覆盖已存在的备份） |
| 每个工程的 `yekitrim.toml` / `polish.toml` | ❌ **不会** —— 只在内存里升级（工程可能几百个、还可能在网络盘上） |

- 迁移**保留注释与键顺序**（走 `toml_edit`，不是重新序列化）。
- 如果配置里的版本号**比程序认识的更新**（比如你换回旧版 exe）：**一个字节都不动**，只打一条 WARN。
- 想回退：拿 `.bak-v0` 覆盖回去即可（那份就是升级前的原样）。

### 2. 发行包里**不再有 `webui/dist/`** —— 界面已编进 exe

**升级操作因此变成：覆盖式解压换掉 exe（+ 托盘），重启。** 不用再管 `webui/dist`。

| | 以前 | 现在 |
|---|---|---|
| 前端 | 运行时读盘，包里带 `webui/dist/`（30 个文件） | **编在 exe 里** |
| 只换 exe 的后果 | **静默**端出旧界面（查找链会命中 exe 旁边那份旧 dist） | 前端跟着 exe 一起换，**不存在错配** |
| dist 过期 | 只在打包时告警 | **编译期直接失败** |

⚠️ **别"删掉整个文件夹再解压"**：数据目录就是 exe 所在目录（`YEKITRIM_DATA_DIR` 可覆盖），
`.yekitrim/`（配置、账号库、**下载好的 ASR 模型**、日志）就在它旁边 —— 删文件夹等于把配置、
账号和几个 GB 的模型一起清掉。包里本来就没有 `.yekitrim/`，覆盖式解压不会碰它。

## 本版主题

1. **托盘瘦身 + 跨进程优雅关停** —— `yekitrim-tray.exe` 从 **57 MB 降到 0.49 MB**；
   服务由独立的 `yekitrim.exe` 承载，关停走一个受保护的 HTTP 控制端点（等价 Ctrl+C）。
2. **界面整体整理** —— 换肤（哥特橙瞳 + 暗色）、设置页重排（分区 + 高级收起 + 死配置下线）、
   全站常显长文字清零、静态内联样式归位工具类、首页「运行状况」面板。
3. **本地模式（免登录单机形态）成型** —— 侧栏/设置按模式收起、首页默认走「服务器文件」、
   项目级主播名可在预处理页改。
4. **配置有了版本号与读时迁移**（上面第 1 条）。
5. **门禁补强** —— 新增跨进程契约判据、工作区换行判据、布局不变式判据（都带变异自证）。

## 逐项

### 托盘：薄启动器 + 受保护的关停端点

- `yekitrim-tray.exe` 不再链接整个服务（那会把静态的 ASR 引擎一起链进来），改成**只起
  `yekitrim.exe server --local-no-auth --open`** 的薄启动器：左键开网页、右键「打开网页 / 退出」。
  **57.4 MB → 0.49 MB**，发行包随之从 ~125 MB 降到 ~68 MB。
- 新增 `POST /api/shutdown`（三道闸：env 未设令牌 ⇒ 404 · 只收 loopback · 令牌常量时间比对），
  效果**等价 Ctrl+C**：优雅关停、锁写成 `pid=0`。
- 托盘退出**不再卡死**（原实现会等 SSE 连接收尾而无上限地等下去）；子进程放进
  `KILL_ON_JOB_CLOSE` 的 Job —— **强杀托盘也不会留下孤儿服务**。
- 顺便修掉"启动时黑框一闪"（全仓子进程统一走 `process::cmd()`）、托盘无图标、exe 无图标。

### 界面

- **换肤**：品牌粉 → **哥特橙瞳**，并出暗色模式（`stores/theme.js` 是唯一写 `data-theme` 的地方）。
- **设置页「程序配置」重排**：分「转写 / 检测 / 输出」三区，13 个调参 + 3 个提示词收进
  「高级参数」默认收起；`config.toml` 的**死配置下线**（4 个字段，见上）。
- **LLM 配置**：去掉折叠全部展开；「按链路覆盖 / extra_params」改左右结构（各占 50%），
  JSON 框高度翻倍（半宽列里滑块改竖排，否则滑条只剩 59px）。
- **首页**：新增「运行状况」面板（ffmpeg/ffprobe + ASR 模型，有问题冒头、正常沉底）；
  「切片总览」改左右分栏（未导出 / 已导出，可只看一栏）；「服务器文件」改左右结构
  （左目录操作 / 右按钮与注意事项）。
- **本地模式**：不显示 admin 与头像、不显示「注册与邀请码」、整页隐藏账号设置、默认走「服务器文件」。
- **全站文案**：常显解释文字 >20 字的一律删掉或压到 20 字以内（细节移进悬停 `title`）；
  账号页与模型管理分离。

### 预处理页

- **项目级主播名**：全局 `[detection] vtuber_name` 只是默认值，每个工程可自己写一份
  （写进工程 `yekitrim.toml`，清空即恢复跟随全局）。改动入口就在预处理页。

### 构建 / 门禁 / 质量

- **WebUI 编进 exe**（内嵌为 release 默认、debug 读盘、`--webui-dir` / `YEKITRIM_WEBUI_DIR` 可覆盖）。
- **新增 3 类判据**：跨进程字面量一致性（托盘 ↔ 服务端）、工作区不许有 CRLF（`w/crlf` 与 `w/mixed`）、
  布局不变式（`.llm-cols` 等宽、滑块跨行、单双栏、`rows ≥ 10`、模板标识符必须有定义）。
  **每条都带变异自证**（改坏源码后判据必须翻面）。
- 前端契约脚本从 7 个增到 8 个；边界门禁 17 条规则。
- 前端两张卡减肥（指令预算一度只剩 **5 B**）。

## 包内容

```
yekitrim-v0.4.1-win-x64/
  yekitrim.exe                 # CLI + WebUI 服务端（界面已编在里面）
  yekitrim-tray.exe            # 托盘薄启动器（可选；要和 yekitrim.exe 放同一目录）
  yekitrim.ico                 # 托盘图标
  resources/fonts/放这里.txt     # 字体库说明（**字体本身已编在 exe 里**，这里只留说明）
  LICENSE · THIRD-PARTY-NOTICES.md
```

- **不含** `.yekitrim/`（配置与模型由首次运行生成；模型需 `yekitrim download` 或界面里下载）。
- 自备 `ffmpeg` / `ffprobe`（在 `PATH` 中）。
- 许可：**Apache-2.0**（允许闭源再分发）；已随包附 `LICENSE` 与 `THIRD-PARTY-NOTICES.md`。

## 升级

**覆盖式解压**到原目录（换掉两个 exe 即可），重启。
⚠️ 别删整个文件夹（理由见开头第 2 条）。首次启动时程序配置会被自动迁移并备份成 `.bak-v0`。

## 已知限制

- 托盘被强杀后服务**不会**留孤儿，但**锁会残留一条 pid**；下次启动会自动接管
  （日志里一句「检测到上次运行残留」）。这是硬终止下唯一可能的结果。
- **Linux 移植已在 Linux 上实测**（2026-10-05）：编译、起服务、界面（两种静态资源来源）、出片管线
  （对拍时长差 **0.000000s**）、门禁与契约脚本**全部通过**；`--data-dir` / `YEKITRIM_DATA_DIR` 逃生口有效。
  **本版仍是 Windows x64 发行包** —— Linux 侧只做了适配测试，未出包。
  ⚠️ **两处 Linux 阻塞已查明**（详见 `docs/plan/linux-adaptation-test-report.md`）：
  ① **ASR 在 Linux 上一跑推理就崩**（`SIGABRT`）—— 根因是**上游预编译 onnxruntime** 把旧 libstdc++ 的
  `std::regex` 静态编进了归档，与滚更发行版（如 Arch）的宿主 libstdc++ 运行期冲突；
  **不在本仓代码**，需换 onnxruntime 构建基线。
  ② **`cargo xtask scan` 在 Linux 上空转**（`SCAN_EXTENSIONS` 只认 `exe`/`dll`，扫不到无扩展名的 ELF）
  —— GPL 产物门禁那道防线在 Linux 上失效（已手工复核产物本身干净）。
  另有两处较小：`render_proc::kill_tree` 传正 pid（杀不掉孙进程）、`scripts/yekitrim-compare.mjs`
  默认字体写死 `C:/Windows/Fonts/msyh.ttc`。
