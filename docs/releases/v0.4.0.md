## 这一版在治什么

**一个病：这个程序有两个名字。**

项目从 `V-Trim` / `vtrim` 全面改名为 **`YekiTrim` / `yekitrim`**（中文「耶斯剪」）。这不是改标题 ——
旧名字**藏在会持久化、会被别的进程读回来的地方**：磁盘上的配置文件名、数据目录名、
数据库文件名、cookie 名、邀请码前缀、webhook token 前缀、前端 localStorage 键、环境变量名。
只改一半的后果是**静默断链**：不报错、界面看不出异常，只是数据对不上。

> ⚠️ **口径（用户拍板）：不做任何向后兼容。**
> 旧目录、旧环境变量、旧 cookie、旧邀请码、旧 localStorage 键**一律不认、不迁移、不提示**。
> 因此这是**破坏性版本** —— 升级前请读 §2「升级影响」。

## 2. ⚠️ 升级影响（破坏性，必读）

| 影响 | 说明 |
|---|---|
| **存量 webhook token 全部失效** | 前缀变了。到设置页**重新生成**，并更新录播姬那侧。 |
| **登录态全部掉线** | cookie 名变了。重新登录即可。 |
| **存量邀请码失效** | 前缀变了。重新生成。 |
| **存量工程需「重新导入」** | 程序只认 `yekitrim.toml`。把 `vtrim.toml` **改名**为 `yekitrim.toml` 即可（程序**不会**自己找）。 |
| 🔴 **逐项目检查点日志失效 ⇒ 要重跑 `polish llm`** | 旧 `.vtrim/` 的检查点不再被读。在长片子上这是**真金白银的 LLM 花费** —— 这是「不做兼容」的**预期代价**，不是 bug。 |
| 前端偏好重置 | 12 个 localStorage 键换了名字，界面偏好回到默认。 |

**迁移做法**：本项目**不提供**迁移工具（口径就是不做兼容）。若你想保留旧工程，
手工把 `<工程>/vtrim.toml` 改名为 `<工程>/yekitrim.toml` 即可；其余（`output/` 产物、媒体）
本来就不带名字，原样保留。

## 3. 改名之外的改动

- **依赖清理**：清掉 3 个僵尸依赖声明（`yekitrim-core` 的 `which`、`yekitrim-polish` 的
  `thiserror`、`yekitrim-render-core` 的 `tracing`）。其中只有 `which` 是真收益 ——
  它不被任何第三方需要，删掉后 `Cargo.lock` 从 383 个包降到 **380**（连带移除 `env_home` / `winsafe`）。
  另两个仍被 `takumi` / `zip` / `axum` / `hyper` / `tower` 需要，删声明只是消除误导。
  扫描工具：`cargo-machete` + `cargo-udeps`（双扫后 0 剩余）。
- **测试质量**：修掉三处既有偶发（真因是三个独立缺陷叠加，不是环境竞态）、
  一处钉错契约的断言（`attempts == 1` 实际钉的是传输层行为，放宽为 `(1..=3)`）、
  一处因果推断错误（"摘掉 X 会红 ⇒ X 必要"缺对照组）。
- **仓库目录名**：`V-Trim` → `YekiTrim`。

## 4. 改名过程中抓到的三类「编译过、测试绿、行为坏」

这三条是本次改名的真实收获，都属**静默失效**（不报错、界面看不出）：

1. **🔴 P0：webhook token 两端前缀不一致**
   生成端写 `yekitrim_`、校验端漏改成 `vtrim_` ⇒ `strip_prefix` 返回 `None` ⇒
   **用户拿到的 token 100% 401**，录播姬采集整条链不可用，且**除 401 无任何线索**。
   修法是**消灭第二个真源**（导出共享常量 `TOKEN_PREFIX`），不是改字符串。

2. **门禁自身被改名削弱**
   `check_module_boundaries.py` 靠 `YEKITRIM_*` 字面量认哨兵，改名后**匹配不到任何东西、
   仍报 0 违规**（空转）。自证：注入 `VTRIM_PATH` → exit 0（漏）；注入 `YEKITRIM_PATH` → exit 1（抓到）。

3. **`is_our_render` 静默失灵**
   `"yekitrim"` **不含** `"vtrim"` 子串（中间是 `ekitrim`）⇒ 只判旧名的判据对新 exe **恒 false** ⇒
   启动清扫认不出遗留渲染进程，ffmpeg / 底座孙进程**永不被回收**（文件被占用且无报错）。
