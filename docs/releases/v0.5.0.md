# YekiTrim v0.5.0

直播录像自动切片：输入录播视频 + 弹幕，输出按事件切好的片段、字幕与发布配置。
带 WebUI（浏览器里做预处理 / 切片 / 精修出片）。

> 上一版 v0.4.3 只做了本地测试、未对外发布；它的内容（识别页右栏重构、
> 任务进度统一口径）也一并进入本版。

## 本版更新

- **主播名只进产物标题**：名字不再烧进切片产物，填错不用重切 ——
  `标题【名】` 在读取/投稿时由 `naming` 一份规则合成；三级取值
  （片段覆盖 > 本项目 > 程序默认），建项目时从录播姬目录名自动填（只填空值）；
- **贴纸包体积上限可配置**：`[stickers]`（默认 1 GiB 上传 / 2 GiB 解压总量），
  前端上传前现取上限，几百 MB 的包不再被写死的 64 MiB 挡住；
- **局域网提速**：字体/贴纸/素材库/缩略图等文件出口统一 ETag/304 + 文本类 gzip，
  `/api` 的 JSON 也 gzip；精修预览优先读 720p 代理（重切后自动补一份）；
  弹幕轨关着不再拉全量 JSON；Dhampir 转译结果按工程 + 字体印章缓存；
- **运镜与位置连续状态**：块缝不再瞬跳（实测 928px/帧）—— 接缝接上一块落点、
  块内走到终点；`speed` 四档与 `cut` 硬切语义落地（模板/预览/转译器/后端四份同改）；
- **编码器真编一次才算数**：无卡机器不再误选 nvenc（以前屏蔽区间剪切悄悄失败，
  最后报成「成片长度与时间线不一致」）；剪切失败立即报错，绝不带屏蔽内容出片；
- **精修产物「文件夹」视图**：左列全部版本（按产出先后）、右侧预览选中的那份；
- **精修页界面一轮**：片段切换卡横排一行（收起=整条折起）、面包屑尾部显示当前
  片段标题、右侧浮动锚点栏；字体下拉不再重复出现同一支字体；
- vendor：sherpa 归档 sha256 字节级白名单（同名换字节必须构建失败，GPL 防线再加一道闩）。

## 需要什么

- `ffmpeg` / `ffprobe` 在 PATH（音频提取与剪切）
- 出片另需 **Node 18+**；Dhampir 底座**已随包**（`dhampir/`，本包为 Linux x64）
- 数据目录默认在 exe 同级，可用 `YEKITRIM_DATA_DIR` 指定，首次启动自动创建

## 安装与启动

覆盖式解压即可（WebUI 已编进 exe，不用另外部署前端；`data/` 是用户数据，别覆盖）。

- Linux：`./yekitrim server --open`（默认只监听 `127.0.0.1:26320`；对外部署见 `docs/deploy.md`）

首次启动会打印管理员初始密码，并写入 `<数据目录>/initial-admin-password.txt`（登录后自动删除）。
