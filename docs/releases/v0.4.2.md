# YekiTrim v0.4.2

直播录像自动切片：输入录播视频 + 弹幕，输出按事件切好的片段、字幕与发布配置。
带 WebUI（浏览器里做预处理 / 切片 / 精修出片）。

**这是第一个公开版本。**

## 需要什么

- `ffmpeg` / `ffprobe` 在 PATH（音频提取与剪切）
- 出片另需 **Node 18+** 与 **Dhampir 底座**（独立仓，不在本包内；缺了会明确报错）
- 数据目录默认在 exe 同级，可用 `YEKITRIM_DATA_DIR` 指定，首次启动自动创建

## 安装与启动

覆盖式解压即可（WebUI 已编进 exe，不用另外部署前端）。

- Windows：双击 `yekitrim-tray.exe`（托盘，本机免登录）；或 `yekitrim server --open`
- Linux：`./yekitrim server --open`（默认只监听 `127.0.0.1:26320`；对外部署见 `docs/deploy.md`）

首次启动会打印管理员初始密码，并写入 `<数据目录>/initial-admin-password.txt`（登录后自动删除）。

## 下载

| 平台 | 文件 |
|---|---|
| Linux x64 | `yekitrim-<版本>-linux-x64.tar.gz` |
| Windows x64 | `yekitrim-<版本>-windows-x64.zip`（含托盘） |

产物**不含** Dhampir 底座与 ffmpeg。
