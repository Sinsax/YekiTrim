# YekiTrim v0.4.2

> 2026-11-14 ｜ Windows x64 + Linux x64 ｜ Apache-2.0 ｜ 上一版 v0.4.1

## 升级必读

1. **目录布局只剩一种：多用户。** 首次启动会把单人时期的存量 `rename` 到第一个管理员名下
   （`resources/` → `users/<管理员>/resources/`、`.yekitrim/{config,llm}.toml` → `users/<管理员>/.yekitrim/`）。
   幂等、只做一次；跨盘失败如实报错并保持原状。**升级前建议备份** `resources/` 与 `.yekitrim/*.toml`。
2. **字幕像素会变。** 出片底座升到 **Dhampir 0.2.0**，字幕栅格化器由 ffmpeg `drawtext` 换成 **libass**：
   字形 / 字距 / 行高 / 描边阴影肉眼可辨；其它画面元素、音轨、工程文件都不变，老工程直接出片即可。
   底座版本契约没动（`project_schema=1` / `host_api=6`），所以**没有自动提示**，只能写在这里。

## 新增

- **公用素材库** `<数据>/global/resources/`：所有账号共享；读=用户库优先、写只写自己的库；内置字体装在 `global/`。
- **账号配额**：管理员可给单个账号设 `users.quota_bytes`（0 = 跟随默认）。
- **剪辑发布标题**：精修页「产物」卡可直接编辑该片段的投稿标题（写 `output/publish_config.json`，投稿链路读它）；
  主播名可开关、可放前/后，完整标题**单击即复制**。

## 修复

- **字体族名映射**：libass 按族名找字体、而 `polish.toml` 存的是库 id —— 对不上会**静默退回 ArialMT** 且检查全绿。
  现出片前把「库 id → 真族名」交给转译器（库外的值原样返回）。
- **打包挑底座**：原先按 mtime 从 `../Dhampir/dist/` 取最新一份，可能静默装进旧底座；现按版本号挑。
- **按账号取路径**：贴纸包构建 / `load_llm_config` / `fonts list` / `stickers list` 此前用单人固定位置
  ⇒ 永远报「包不存在」「未配置」；素材库路径也各自按库显示（此前三类都显示成视频库）。
- **设置页「未保存改动」**：刚进页面什么都没点就弹框的误报。
- **启动护栏**：对外监听仍拒绝初始密码，但错误信息直接给出带 `YEKITRIM_DATA_DIR` 的完整改密命令。

## 安装 / 升级

- **换 exe 即可**（WebUI 已编进 exe）：覆盖式解压，**别删整个目录**（`.yekitrim/` 就在 exe 旁边）。
- 依赖：`ffmpeg` / `ffprobe` 在 PATH；出片另需 **Node 18+** 与 **Dhampir 底座**（不在本仓）。
- 数据目录：`YEKITRIM_DATA_DIR` ?? exe 同级。

## 产物

GitHub Actions 在推 `v*` tag 时构建并附到本页：

| 平台 | 产物 |
|---|---|
| Linux x64 | `yekitrim-<版本>-linux-x64.tar.gz` |
| Windows x64 | `yekitrim-<版本>-windows-x64.zip`（含 `yekitrim-tray.exe`） |

⚠️ 产物**不含 Dhampir 底座**（独立仓），也不含 `ffmpeg`。
