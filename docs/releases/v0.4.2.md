# YekiTrim v0.4.2

Windows x64 / Linux x64 ｜ Apache-2.0 ｜ 上一版 v0.4.1

## 升级前必看

1. **数据目录改为多用户布局**：首次启动会把旧的 `resources/` 与 `.yekitrim/{config,llm}.toml`
   自动移到 `users/<管理员>/` 下（只做一次；跨盘失败会报错并保持原状）。**升级前备份这两处。**
2. **字幕像素会变**：出片底座升到 Dhampir 0.2.0，字幕改用 libass 渲染。
   工程文件完全兼容，其余画面元素与音轨不变。

## 安装

- **覆盖式解压、只换 exe**（WebUI 已编进 exe；别删整个目录，`.yekitrim/` 就在它旁边）。
- 需要 `ffmpeg` / `ffprobe` 在 PATH；出片另需 Node 18+ 与 **Dhampir 底座**（独立仓）。

## 下载

| 平台 | 文件 |
|---|---|
| Linux x64 | `yekitrim-<版本>-linux-x64.tar.gz` |
| Windows x64 | `yekitrim-<版本>-windows-x64.zip`（含托盘） |

产物**不含** Dhampir 底座与 ffmpeg。
