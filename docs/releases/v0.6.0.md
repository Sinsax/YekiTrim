# YekiTrim v0.6.0 — 目录布局收敛（app/ + data/）

这一版只做一件事：**把安装目录收敛成两个根**。程序件只读、运行态可写，
不再需要解释 `.yekitrim/`、`cloud/`、`global/resources/`、`resources/` 各是什么。

## 新布局

```
<程序>/
├── yekitrim.exe / yekitrim-tray.exe / yekitrim.ico
├── LICENSE / THIRD-PARTY-NOTICES.md / RELEASE-NOTES.md
├── app/                 # 只读程序件（升级整目录替换）
│   ├── runtime/{polish-to-dhampir.mjs,effects.json}
│   └── dhampir/{bin,preview,VERSION}
└── data/                # 全部可写（备份只搬它）
    ├── layout.json
    ├── server.toml
    ├── ledger/{yekitrim.db*,yekitrim.lock,initial-admin-password.txt,render-procs}
    ├── logs/{tray.log,yekitrim-*.log,render-*.log,llm/}
    ├── models/{sensevoice,qwen3-asr,silero-vad}
    ├── bin/yt-dlp.exe
    ├── projects/users/<uid>/<room>/<stamp>-<pid>/
    ├── shared/{fonts,stickers,videos}
    └── users/<uid>/{config.toml,llm.toml,fonts,stickers,videos}
```

- 首次启动自动创建 `data/`；发布包里**没有** `data/`。
- `--data-dir` / `YEKITRIM_DATA_DIR` 现在表示**数据根**（账本在 `<data>/ledger/`）。
- 字体：账号库 `<data>/users/<uid>/fonts`，公用库 `<data>/shared/fonts`（自带字体首启落这里）。
- 模型：`<data>/models`（debug/release 共用一份就指同一个 `YEKITRIM_DATA_DIR`）。

## 从 0.5 升级

启动时自动迁移旧树，幂等、只 `rename`、绝不覆盖已有目标；未知条目进 `data/legacy/`。
也可以先看计划再执行：

```bat
yekitrim migrate-layout --root E:\yekitrim-v0.5.0-win-x64
yekitrim migrate-layout --root E:\yekitrim-v0.5.0-win-x64 --apply
rem 出问题可回滚：--rollback <journal.json>
```

迁移后**不要再用 0.5 的 exe 启动**（它会找不到 `.yekitrim/` 并新建空状态）。
只换 exe、不搬目录也能跑：`app/` 缺失时会回落旧 `<程序>/runtime`、`<程序>/dhampir`。

## 其它

- `yekitrim migrate-layout` 新命令：默认 dry-run，`--apply` 执行，`--rollback` 回滚，`--force` 接管陈旧锁。
- 打包门禁新增包根形状检查：只允许 `app/` + 顶层文件，`app/runtime` 两件必须在。
- 录播姬入库策略未改（后续单独重做）；`data/projects` 仍是 B 站下载与入库的默认托管根，可按需覆盖。
