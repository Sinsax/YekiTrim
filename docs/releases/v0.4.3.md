# YekiTrim v0.4.3

直播录像自动切片：输入录播视频 + 弹幕，输出按事件切好的片段、字幕与发布配置。
带 WebUI（浏览器里做预处理 / 切片 / 精修出片）。

## 本版更新

- **首页「运行状况」并入「检查项」**：ffmpeg / ffprobe / 出片底座的实测状态在「运行环境」行
  逐项可见，缺哪项当场指路（底座缺失曾出现"报 1 项待处理、展开却全绿"的悬案）；
- 模型清单与下载（仅管理员）随「字幕模型」行内嵌；独立的「运行状况」卡与页头汇总提示删除，
  全部就绪时检查项收成一行「开始使用 · 环境就绪」；
- 读失败照实报：运行状况读失败显示原句 + 重新检查，不再拿旧快照冒充现状；
- 能力位契约同步：`home.doctor` 退役（`home.setup-checklist` 承接）。

## 需要什么

- `ffmpeg` / `ffprobe` 在 PATH（音频提取与剪切）
- 出片另需 **Node 18+**；Dhampir 底座**已随包**（`dhampir/`，本包为 Linux x64）
- 数据目录默认在 exe 同级，可用 `YEKITRIM_DATA_DIR` 指定，首次启动自动创建

## 安装与启动

覆盖式解压即可（WebUI 已编进 exe，不用另外部署前端；`data/` 是用户数据，别覆盖）。

- Linux：`./yekitrim server --open`（默认只监听 `127.0.0.1:26320`；对外部署见 `docs/deploy.md`）

首次启动会打印管理员初始密码，并写入 `<数据目录>/initial-admin-password.txt`（登录后自动删除）。
