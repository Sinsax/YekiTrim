# WebUI v6 重构方案（范围覆盖全部 9 个页面）

> 状态：执行中 ｜ 上游纪律：`webui/AGENTS.md` + `webui/src/{,styles,components,views,polish}/AGENTS.md` ｜ 验证：`npm --prefix webui run build` + 18 个 `check-*.mjs` + 两条仓库门禁

## 0. 为什么重做

v5 的界面是"功能逐个加出来的"：每个页面都自己决定卡片怎么排、标题多大、按钮放哪。
结果是三层问题叠加：

1. **视觉层没有系统**：字号有 9/9.5/10/10.5/11/11.5/12/12.5/13/13.5 十档，间距靠 `mt-6/mt-8/mb-12` 散点拼，
   卡片阴影与描边混用，页面之间不像同一套产品。
2. **结构层是"卡片堆"**：首页把三个来源向导横排成三列、单页超过 2000px 高；精修页把预览、右栏、
   时间轴塞进同一个 `cols-main`，没有"画布 / 检视器 / 时间线"的层次。
3. **交互层只到"能用"**：没有命令面板、没有键盘导航、没有批量选择、没有页面转场、加载只有骨架条。

上一轮只修了壳与基础件（Toast/Modal/焦点/响应式/token 对比度），**属于止血，不是重构**。
v6 要动的是上面三层。

## 2. 设计系统 v6

### 2.1 尺度 token（新增，全部主题无关）

```css
:root {
  /* 间距：4 的倍数，页面只用这八档 */
  --s-1:4px;  --s-2:8px;  --s-3:12px; --s-4:16px;
  --s-5:24px; --s-6:32px; --s-7:48px; --s-8:64px;

  /* 字号：正文 13，只有这七档 */
  --fs-xs:11px; --fs-sm:12px; --fs-base:13px; --fs-md:14px;
  --fs-lg:16px; --fs-xl:20px; --fs-2xl:26px;

  /* 字重 */
  --fw-normal:400; --fw-medium:550; --fw-semi:650; --fw-bold:700;

  /* 行高 */
  --lh-tight:1.3; --lh-base:1.6;

  /* 圆角：卡片 14、控件 10、胶囊 999 */
  --r-xs:6px; --r-sm:10px; --r-md:14px; --r-lg:20px; --r-full:999px;

  /* 动效 */
  --dur-fast:120ms; --dur-base:180ms; --dur-slow:260ms;
  --ease: cubic-bezier(.2,.7,.3,1);
}
```

⚠ 现有 `--r-sm:10px / --r:16px / --r-full` 已被 100+ 处引用。**不重命名**，
新增 `--r-md` 后把卡片逐步迁到 `--r-md`，`--r` 保留为别名（=14px 会改变现有观感，需逐页核对）。

### 2.2 表面 / 层级 token

```css
:root {
  --surface-0: var(--bg);        /* 页面底 */
  --surface-1: var(--card);      /* 卡片 */
  --surface-2: var(--bg-soft);   /* 卡片内嵌区（输入、列表行、代码块） */
  --surface-3: var(--line-soft); /* 分隔、轨道 */
  --border: 1px solid var(--line);
  --border-soft: 1px solid var(--line-soft);
  --e-0: none;
  --e-1: 0 1px 2px rgba(32,32,32,.04);
  --e-2: 0 4px 12px rgba(32,32,32,.06);   /* 悬浮卡片 */
  --e-3: 0 12px 32px rgba(32,32,32,.14);  /* 弹层 */
}
:root[data-theme="dark"] { --e-1: 0 1px 2px rgba(0,0,0,.30); --e-2: 0 4px 14px rgba(0,0,0,.40); --e-3: 0 14px 36px rgba(0,0,0,.55); }
```

**规则**：静态卡片 = `--border` + `--e-1`；可点卡片 hover 才升 `--e-2`；
弹层/抽屉/命令面板才用 `--e-3`。杜绝"每张卡都浮起来"。

### 2.3 页头 / 分区 / 工具条（新的三段式）

```
┌ 页头 ────────────────────────────────┐  title 26/650 + desc 13/dim + actions 右
├ 工具条（可选） ────────────────────────┤  过滤 · 搜索 · 排序 · 视图切换，紧凑一行
├ 内容 ────────────────────────────────┤  卡片/表格/网格
```

- 页头下边距 `--s-5`(24)，工具条与内容之间 `--s-4`(16)
- 分区标题：16/650 + 右侧 actions；分区之间 `--s-6`(32)
- 卡片内边距统一 `--s-4`(16)；大卡 `--s-5`(24)

## 7. 风险与纪律

1. **精修页**最危险：`PolishPreview` 重挂 = 黑屏；时间轴几何被 ⑰ 钉死。P5 拆成三个可回滚子步。
2. **`data-cap` 锚点**只许移动、不许删；移动后必须跑 `check-simplify`。
3. **`webui/dist` 入库**：每次改 `webui/src`（含 `.md`）都要重建，指纹覆盖全目录。
4. **不要引依赖**：无 UI 库、无图标库、无动画库；图标继续走 `Icon.vue`（本轮补齐到 ~60 个）。
5. **几何断言**：每个页面改动都要 `getBoundingClientRect()` 宽高 > 0 + 无横向溢出，四档视口。
6. **双主题成对**：新增 token 亮暗各一份，改完用脚本算对比度。
