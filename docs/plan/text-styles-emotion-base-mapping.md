# 文字元素样式 · 情绪分配与底座能力对照

> 2026-10-12 定稿。配合 `docs/plan/text-styles-comic-draft.html`（39 档效果稿）阅读。
> 口径：文字元素 == 贴纸（画面上的贴片），不带背景元素；情绪词沿用贴纸库 tag。

---

## 〇、一句话结论

**样式 21 档全部做不到**（依赖逐字变换 / 整块倾斜 / 竖排 / 字距，底座一个字段都没有）；
**动效 18 档里 16 档能做** —— 因为底座的 `shake_px` / `scale_in_*` / `fade_*` 已经覆盖了
"整块动"的全部需求。

⇒ **落地路线应该是"动效先上、样式后补"**，而不是反过来。

---

## 一、能分散到哪些情绪

### 1.1 样式 × 情绪

| 样式 | 能演的情绪 | 贴纸 tag 对应 | 底座 |
|---|---|---|---|
| **倾斜** | 不稳、用力、不服；正角度 = 撒娇求饶 | 生气 / 害羞 | ✗ |
| **弧形** | 笑到起浪、唱、念白；下垂 = 叹气 | 笑 / 其他 | ✗ |
| **大小字** | 重音（爆发在末字 / 一开口就爆 / 强调实词） | 生气 / 惊讶 | ✗ |
| **逐字抖散** | 心里发毛 → 彻底慌了（幅度分级） | 害怕 / 紧张 | ✗ |
| **竖排** | 日漫恐怖、压迫、警告标语 | 害怕 | ✗ |
| **逐字变小** | 泄气、认命、欲言又止、迟疑 | 呆 / 其他 | ✗ |
| **逐字放大** | 由衷赞叹、情绪失控、拟声巨响 | 开心 / 惊讶 | ✗ |

### 1.2 动效 × 情绪

| 动效 | 能演的情绪 | 关键参数 | 贴纸 tag | 底座 |
|---|---|---|---|---|
| **抖动** | 害怕 → 虚弱 → 极度恐慌 | **频率**（70/110/260ms） | 害怕 / 紧张 | ✓ |
| **摇摆** | 笑 / 得意；慢摆 = 醉、眩晕 | **角度 + 周期** | 笑 / 得意 | ✓ |
| **砸入** | 意外、巨响；重 = 震惊；带压扁 = 生气重击 | **起点倍数**（2.4/3.4×） | 惊讶 / 生气 | ✓ |
| **收缩** | 无奈、放弃、被打断 | **时长**（500/1600ms） | 呆 / 无奈 | ✓ |
| **弹出** | 可爱、被萌到；软 = 温柔回应 | **起点倍数**（.4/.7×） | 开心 / 害羞 | ✓（圆角版✗） |
| **逐字跳起** | 欢快、连珠炮；慢跳 = 从容 | **错峰间隔**（50/110ms） | 开心 | ✗ |

### 1.3 四个"情绪族"的完整配方

把样式和动效组合起来，一个情绪才立得住：

| 情绪族 | 样式 | 动效 | 合成效果 |
|---|---|---|---|
| **爆发**（生气 / 惊讶） | 大小字 · 末字重音 + 倾斜 | 砸入 · 带压扁 | 歪着砸进来，末字爆开 |
| **失控**（害怕 / 紧张） | 逐字抖散 · 重 + 竖排 | 抖动 · 强 | 字散架了，还在颤 |
| **欢快**（开心 / 笑） | 弧形 · 上拱 + 逐字放大 | 逐字跳起 · 标准 | 排成弧线，逐字蹦起来 |
| **泄气**（呆 / 无奈） | 逐字变小 · 递减 | 收缩 · 标准 | 字越写越小，缩着淡掉 |

### 1.4 ⚠️ 刻意做成"反义词"的几对

这是这套体系里最值钱的部分 —— **同一手法反向用就是另一个情绪**：

| 正向 | 反向 | 情绪差 |
|---|---|---|
| 倾斜 -6°（生气） | 倾斜 +5°（撒娇） | 硬 ↔ 软 |
| 弧形上拱（笑） | 弧形下垂（叹气） | 扬 ↔ 沉 |
| 逐字变小（泄气） | 逐字放大（涨上去） | 收 ↔ 放 |
| 抖动慢频（虚弱） | 抖动强频（恐慌） | 没力气 ↔ 失控 |
| 摇摆快摆（笑） | 摇摆慢摆（晕） | 兴奋 ↔ 昏沉 |
| 砸入（冲击） | 弹出（可爱） | 大→小 ↔ 小→大 |
| 收缩慢（自己泄气） | 收缩快（被抽走） | 主动 ↔ 被动 |

## 二、哪些底座做不到

底座 `SubtitleStyle` 共 **31 个字段**，逐条对照后：

### 2.1 底座**有**的（今天就能出片）

| 能力 | 字段 | 本稿用到的档 |
|---|---|---|
| 字号 | `font_ratio` | 全部 |
| 字重 | `font_weight` | 全部 |
| 字色 / 描边宽 / 描边色 | `color` / `stroke_ratio` / `stroke_color` | 全部 |
| 底衬色 + 内边距 | `plate_color` / `plate_pad_px` | 弹出 · 标准 |
| 字体族 | `font_family` | 竖排 · 细楷 |
| 行高 | `line_height` | — |
| 投影 | `shadow_*`（4 个） | — |
| 抖动 | `shake_px` / `shake_hz` / `shake_phase` | **抖动 3 档** |
| 弹入缩放 | `scale_in_from` / `scale_in_peak` / `scale_in_ms` | **砸入 3 档 / 弹出 3 档** |
| 淡入淡出 | `fade_in_ms` / `fade_out_ms` | **收缩 · 只淡出** |
| 纵横锚点 | `anchor_bottom` / `bottom_margin` | 全部 |

### 2.2 底座**没有**的（要动 Dhampir）

| 能力 | 影响本稿几档 | 要动哪里 | 成本 |
|---|---|---|---|
| **逐字字号** | 9 档 | 排版层：一行一个字号 → 逐字可覆盖 | 中 |
| **逐字旋转 / 位移** | 6 档 | 同上 + 栅格化后要逐字定位 | 中 |
| **整块倾斜** | 3 档 | `TransformV2.rotation` **已存在**，但文字路径不读它 ⇒ 让 `text_overlay` 读一次即可 | **很低** |
| **压扁拉伸** | 1 档 | `TransformV2` 只有等比 `scale`，非等比要加字段 | 低 |
| **竖排** | 3 档 | 排版方向，要重写折行 | **高** |
| **字距** | 2 档 | 排版层加字距 | 低 |
| **底衬圆角** | 2 档 | `PlateRect` 加 radius + 四角判断 | **低** |
| **底衬描边** | 0 档（稿里没画，但漫画对话框需要） | `PlateRect` 加边框绘制 | 低 |
| **逐字错峰动画** | 3 档 | 每个字独立时间轴 | **高** |

### 2.3 落地建议：三批做

**第一批（零底座改动，今天就能出片）** —— 覆盖 16/18 动效档：
- 抖动 3 档（`shake_px/hz/phase` 已有，**只差界面入口**）
- 砸入 3 档（`scale_in_*` 已有，**已接通**）
- 弹出 1 档（同上）
- 收缩 · 只淡出（`fade_out_ms` 已有）
- 摇摆 3 档 ✅ **已查证能做**（2026-10-12 修正）：`Layer.TransformV2` 有 `rotation: f32`，
  `TRANSFORM_TARGETS` 里 `rotation` 是**一等公民关键帧目标**，字幕轨也有 `layers: Vec<Layer>`
  ⇒ 往复摇摆**今天就能配关键帧**。唯一的缺口是 `text_overlay.rs` 不读 transform，
  接上即可（见 `text-option-d-scope.md`）。
  ⚠️ 本行此前误判为"要查清楚/需近似"，**已修正**。
- 跳起 3 档 ⚠️ 逐字错峰，实际属第三批

**第二批（低成本动底座，性价比最高）**：
- **整块倾斜**（让 `text_overlay` 读已有的 `TransformV2.rotation`）→ 解锁「倾斜 3 档」+「摇摆 3 档」
- **非等比 scale**（`TransformV2` 加一个字段）→ 解锁「砸入·带压扁」
- **底衬圆角 + 底衬描边**（同一处 `PlateRect`）→ 解锁「弹出 2 档」+ 漫画对话框观感
- **字距**（排版层一个小参数）→ 解锁「竖排·细楷」

**第三批（高成本，看效果再定）**：
- **逐字变换**（字号/旋转/位移）→ 一次解锁 15 档样式（大小字 / 弧形 / 抖散 / 变小 / 放大）
- **逐字错峰动画** → 解锁「跳起 3 档」+「弹出·逐字」

## 三、还欠着的判断

1. ~~摇摆要不要用横移近似？~~ **已解决**：不用近似。`rotation` 是关键帧目标，
   接上 `text_overlay` 即可拿到**真正的旋转摇摆**（见 `text-option-d-scope.md`）。
2. **竖排值不值得做？** 成本最高（要重写折行），但只有 3 档用到，且都有替代
   （「害怕」可以用逐字抖散 + 抖动）。
3. **逐字变换是不是应该先做字号一项？** 字号是 7 种样式里用得最多的（9 档），
   旋转/位移次之。先只做逐字字号，能拿下一半。
