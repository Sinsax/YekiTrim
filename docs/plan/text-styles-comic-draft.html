文字元素样式 · 情绪靠形态与动态

两个轴一起做：形态（字怎么排）+ 动态（字怎么动）。 形态那一版解决了"大差不差"；这一版补上动态 —— 因为同一句话，动法不同情绪也不同： 「啊？！」砸进来是惊吓，慢慢推近是紧张。

为什么形态才是情绪的载体。同样一句"太吵了吧"：平排 = 陈述； 末字放大 = 爆发；逐字旋转 = 抱怨；整体歪+压扁 = 冲击；拉开字距 = 迟疑；竖排 = 恐怖。 字没变、颜色没变，情绪全变了。
⚠️ 下面画的是文字贴片本身（无背景元素）；底纹换成三种只为检验可读性。 ⚠️ 其中逐字变换 / 倾斜 / 竖排 / 底衬圆角今天到不了成片 —— 底座没有这些字段。

总结一 · 文字排版手法

把"字"当积木，能动的只有四组东西。前两组是真正区分情绪的，后两组只是修饰。

组手法怎么用本稿哪几档在用底座
一 · 逐字
每个字各自不同		 字号末字撑大=重音；逐字递减=泄气 大小字（3 种）／逐字变小／逐字放大 ✗
旋转逐字成弧=笑；逐字歪=抖 弧形（3 种）／逐字抖散✗
位移逐字上升=开心；错位=颤抖 弧形（3 种）／逐字抖散✗
粗细同句细↔粗对撞=情绪转折 大小字 · 中字重音／逐字放大✗
二 · 整块
整句话一起变		 倾斜歪着贴=不稳、用力 倾斜（3 种）／砸入 · 带压扁✗
压扁 / 拉伸拉伸=冲击；压扁=重击 倾斜（3 种）／砸入 · 带压扁（下拉）✗
字距收紧=咬牙；拉开=迟疑 大小字（字距收紧）／逐字变小 · 尾音✗
竖排竖写=日漫、压迫 竖排（3 种）／竖排 + 逐字变小✗
三 · 字的皮
不变形状，只换皮		 字号 / 字重整块放大、加粗 全部 39 档✓
字色 / 描边白+黑边最通用；黄+黑边抓眼 全部 39 档✓
字体族黑体硬（生气）／楷体软（害怕）／雅黑中性 竖排（3 种）／竖排 + 逐字变小（楷体）✓
四 · 底衬
字背后的色块		 颜色 / 直角色块 = "这段是重点" 倾斜（3 种）／砸入 · 带压扁／弹出 · 标准（药丸底衬）✓
内边距撑大 = 从"色块"变"色带" 弹出 · 标准（药丸底衬）✓
圆角圆角/药丸 = 柔和、气泡感 弹出 · 标准（药丸底衬）✗

一句话结论：真正区分情绪的全在第一、二组（逐字 + 整块变换）， 而这两组底座一个字段都没有。第三、四组（字号/颜色/底衬）现在就能出片， 但它们只决定"好不好看"，决定不了"是什么情绪" —— 这正是前面几版"大差不差"的根本原因。
